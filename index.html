Quick Stage:
💾 กดปุ่ม “บันทึกข้อมูล” เมื่อลงข้อมูลเสร็จ — ระบบบันทึกข้อมูลลง SharePoint List ส่วนกลาง โดยใช้ Stage แทน Detail • งานที่เสร็จเร็วกว่าแผน กดปุ่ม Advance ท้ายชื่อขั้นตอน ✕
📌 โหมดลงข้อมูลวันนี้ — • แสดงเฉพาะงานที่มีแผนตรงวันนี้ วันนี้ และงานค้าง ค้าง
✏️ โหมดแก้ไขแผน — คลิก/ลากบนช่องวันเพื่อเพิ่มหรือลบวันตามแผน • กด Alt ค้างแล้วลากเพื่อเลื่อนทั้งแท่ง

📘 คู่มือการใช้งาน Dashboard V2.6.1 ✕

1
ตั้งค่า Flow ครั้งแรก — กด ตั้งค่า Flow ที่ส่วนหัว แล้วกรอก Read Flow URL และ Write Flow URL ระบบจะจำ URL ไว้ใน Browser เครื่องนี้
2
เพิ่มหรือแก้ไขแผน — กด ＋ เพิ่ม/แก้ไขงาน แล้วเลือก Project, Process, PIC, Stage, Start Date และ End Date; Progress, Status และ Completed คำนวณอัตโนมัติ
3
เลือก Cut-off — Cut-off คือวันที่ใช้คำนวณสถานะ Not started, On plan, Delay และ Advance รวมถึงเส้นแบ่งใน Gantt
4
ลง Actual — คลิกหรือลากได้เฉพาะช่องที่มี Plan และวันที่ไม่เกิน Cut-off; ช่องว่างหรือวันที่หลัง Cut-off จะกดไม่ได้
5
Advance / Completed — ถ้างานเสร็จก่อนใช้ครบทุกวันตาม Plan ให้กด Advance; ถ้า Actual ครบจำนวนวัน Plan ระบบจะแสดง Completed อัตโนมัติและซ่อนปุ่ม Advance
6
Import Excel — เมนูคำสั่ง → Import Excel รองรับตารางแบบแถวที่มี Project, Process, PIC, Stage, StartDate, EndDate และ Master Schedule แบบเดิม
7
Stage Manager — เพิ่ม Stage ใหม่ แก้ Group/Color/Token และเลื่อนลำดับได้จากเมนูคำสั่ง โดยไม่ต้องแก้ Source Code
8
กรองและบันทึก — ใช้ Quick Stage หรือ Detail Filter เพื่อเลือกกลุ่มงาน จากนั้นกด บันทึกข้อมูล หรือ Ctrl + S เพื่อส่งเฉพาะรายการที่เปลี่ยนไปยัง SharePoint ผ่าน Power Automate
สถานะ: Delay = ช้ากว่าแผน • On plan = ตามแผน • Advance = เสร็จก่อนแผน • Completed = งานปิดแล้ว
